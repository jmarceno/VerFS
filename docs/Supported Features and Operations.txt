VeratyFS File System
- Version 0.0.5
- Variable Block Size
- Inline Dedup at Block Level
- Transparent InLine Compression (only for data that the system consider the compression potential to be worth the speed trade-off)
- 
- Planned:
- Cloud Sync and Mount
- Posix Compliant
- Software RAID (z-RAID like)

- truncate (neither by path or by fd)
